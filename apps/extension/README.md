# OpenFox Chrome 侧边栏

浏览网页时，可以在 Chrome 侧边栏选择 OpenFox 空间和 Agent，开始新对话或接续历史会话。勾选“引用当前页面”后，这一次发送的消息会带上页面标题、地址和选中的文字。

## 安装与登录

1. 在 Chrome 116 或更新版本打开扩展管理页，开启开发者模式。「加载已解压的扩展程序」选择安装包解压后含 `manifest.json` 的目录。
2. 点击工具栏上的 OpenFox 图标。当前 Chrome 配置已登录工作台时，侧栏直接显示对话。
3. 首次使用时点「登录 OpenFox」，在新标签页完成工作台的邮箱验证码登录。返回侧栏即可使用。网页登录、退出和换账号会同步到侧栏。

工具栏操作也可以通过 Alt+Shift+C（macOS 为 Option+Shift+C）触发。快捷键冲突时可在 `chrome://extensions/shortcuts` 设置。

## 对话与引用

- 选择空间与支持单聊的 Agent，输入文字后点击“发送”，或按 Ctrl+Enter / ⌘+Enter。第一条消息创建私有会话。
- 在“历史会话”中打开当前空间已有的对话，“加载更多会话”和“查看更早消息”可继续翻页。已关闭的会话可阅读。
- 要引用网页，先在目标网页调用扩展，选中文字并勾选“引用当前页面”。扩展读取主页面的选区，地址保留来源与路径，选区上限为 8,000 个字符。成功发送后，勾选自动清除。对话中的网页引用显示标题和站点，展开可查看选区与完整地址。换到其他网站时需要重新点击扩展图标取得临时访问权。
- 网络中断后，可以用原草稿重试。扩展在当前面板内复用上次发送时的正文、页面快照与消息 ID。关闭面板会结束这次草稿。
- 回复通过 OpenFox 的消息接口更新。运行 Agent 需要它在 OpenFox 中具备可用的执行环境。

## 工作台与浏览器权限

安装包对应一个 OpenFox 工作台。部署端构建时沿用 `OPENFOX_PUBLIC_URL`，本地开发默认使用 Web 工作台的 `http://127.0.0.1:4173`。自托管部署设置为自己的 HTTPS 工作台来源后构建，同一份包分发给该工作台的用户。

| 权限                      | 用途                                                                                                         |
| ------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 工作台站点权限、`cookies` | 对固定工作台发起当前浏览器会话的请求；仅读取该站点的 CSRF 标记用于写入校验，登录 Cookie 由 Chrome 随请求发送 |
| `sidePanel`               | 通过工具栏或快捷键打开侧栏                                                                                   |
| `activeTab`、`scripting`  | 用户主动引用时读取当前页面的标题、地址和选区                                                                 |

切换 Chrome 用户配置时，侧栏使用该配置自己的账号。在工作台登出会让侧栏回到登录入口，换账号会清除旧对话和草稿。若浏览器策略限制站点访问或会话 Cookie，需允许此工作台后重试。

## 开发校验

```sh
pnpm install --frozen-lockfile
pnpm --filter @openfox/extension typecheck
pnpm exec vitest run apps/extension
pnpm --filter @openfox/extension build
```
