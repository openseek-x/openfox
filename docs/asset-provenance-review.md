# 图标与图形来源核对清单

`packages/ui/src/icons/data.ts` 当前包含 313 个内嵌 SVG 图标。本清单仅记录现存图形；原始创作来源、使用权和按本仓库许可证再分发的许可尚未核实，不能据此认定已经获授权，也不能据此认定图形侵权。

发布前优先核对 56 个项目专属图标与 27 个第三方品牌图标；品牌标识还应核对商标使用条件。其余图标也需确认来源，无法确认时应替换为许可证明确、适合本项目的图形，并保留所需署名和许可证说明。
