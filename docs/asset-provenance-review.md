# 公开版图形来源与许可

公开源码保留 313 个 UI 图标键。功能图标由 Lucide 的 215 个 SVG 图形绘制。项目选取了 npm 发布包 `lucide-static@0.468.0` 的 `icons/*.svg`；图标数据表中 `lucide` 的每个键就是上游文件名。描边沿用上游 SVG 的设置，颜色随界面文字变化。[上游版本](https://www.npmjs.com/package/lucide-static/v/0.468.0) · [本地映射](../packages/ui/src/icons/data.ts)

Lucide 使用 ISC 许可证，其中源自 Feather 的图形适用 MIT 许可证。两份版权及许可声明随源码提供，Web 构建同时复制到 `static/licenses/lucide/LICENSE.txt`。[随附许可全文](../packages/ui/src/icons/LICENSE-lucide.txt) · [上游许可说明](https://lucide.dev/license)

OpenFox 的卷尾狐标志取自本项目生成并选定的设计。网页、macOS 应用及 Teams 安装包使用这张图的尺寸与配色变体。[网页标志](../packages/ui/src/icons/openfox.png)

集成服务、运行时和操作系统标记使用系统字体渲染的文字缩写。通用代码托管图标使用 Lucide 的 Git 分叉图形。分拣空状态插图取自同一组许可明确的图形。状态、优先级、进度、图表和加载动画由界面代码绘制，二维码和 PDF 选区几何由对应数据生成。测试 Office 文件及其中的图形来源另见夹具说明。[Office 夹具](../tests/frontend/e2e/fixtures/office-preview/README.md)
