# OPE-24 发布检查修复

PR #37 的 Go 检查失败后，GitHub 取消了同一矩阵中的 Web 检查。单独运行浏览器回归时，Agent 目录和打开产物预览后的消息发送均出现超时。

- 新建对话菜单只在展开时请求联系人。原来侧栏按钮在每个组织页面都会挂载，菜单关闭也会发起请求；在 Agent 目录回归中，测试替身没有提供该接口的数据，导致整个页面进入错误边界。两个新建对话入口的单测都检查了首次点击前的请求，并继续验证点击后能搜索联系人、发起聊天。
- 会话外框和聊天列分别作为 CSS 容器。产物面板根据外框的 720px 断点选择分栏或覆盖布局，顶栏继续依据聊天列宽度折叠。原来宽屏上预览也覆盖整个会话，发送按钮收不到点击。
- GitLab 的回链测试等待数据库中的评论 ID 与模拟 GitLab 实际返回的 ID 一致。原断言可能在回写事务提交前读取空值。
- Go 与 Web 检查独立执行。集成测试失败时，作业输出同时列出失败用例名，以便直接定位。

## 验证

- 使用真实浏览器复现了 Agent 目录错误页和产物面板拦截点击。修复后，Agent 资料卡、HTML 批注、图片批注及 OPE-24 桌面与窄屏用例共 8 项通过。
- 两个新建对话入口的新增断言在修复前均失败。修复后，直接聊天和侧栏导航测试共 19 项通过。
- 在隔离 PostgreSQL 中将 GitLab 回链 ID 的写入延迟 350 毫秒，原断言失败，修复后该包 29 项全部通过。
- 初次 CI 仅记录 stage3 失败数，缺少用例名。同一提交按原分库规则复跑，主库 458 项通过、13 项为预期跳过，另两个专用库的 7 项测试均通过。

## Jira 绑定测试

远端 Web 首轮检查中，Jira ACTIVE 用例在设置页仍处于加载阶段时就耗尽了全页按钮查询的 1 秒默认等待。测试现在先等待对应站点的个人账号区域就绪，再在该区域点击绑定按钮。提交的数据、版本及对话框关闭断言均保留。模拟 Jira 详情响应延迟 1350 毫秒时，原用例失败，修订后的用例通过；四项 Jira 与禅道绑定用例在通常延迟下全部通过。
