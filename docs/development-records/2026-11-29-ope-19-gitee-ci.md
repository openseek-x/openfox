# OPE-19 · Gitee 回链集成测试

PR #32 的 Go 作业在 Gitee 测试中记录了 27 项通过、2 项失败。该次作业仅输出计数，未保存失败用例名。

Gitee 接受 PR 回链评论后，OpenFox 的后台任务在独立事务中保存返回的评论 ID。旧用例一看到模拟 Gitee 中的评论，就读取数据库。测试现在分别等待评论出现和事务提交，并校验数据库记录与该条评论的 ID 相同。集成测试运行器在失败时同时输出用例名称和原有计数。

| 隔离 PostgreSQL 场景 | 实测结果 |
| --- | --- |
| 在 PR 21 的回链 ID 写入前增加 250 毫秒延迟 | 修复前子测试和父测试均失败，修复后 Gitee 测试包连续 8 轮通过 |
| 正常写入 | 修复后 Gitee 测试包连续 10 轮通过 |
| 写入另一个评论 ID | 断言按预期失败，运行器退出 1，日志列出 `TestGitee/pull_request_backlink` 和 `TestGitee` |
