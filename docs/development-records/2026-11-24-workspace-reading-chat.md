## 目标与取舍

## 实现

1. 在 ChatPage 主区增加“选择成员、Agent 或小队”按钮，与侧栏共用对象选择器和现有选人逻辑。新 Agent 和小队对话将身份、运行提示和输入区集中在同一栏，已有消息的会话仍使用底部输入区。同步中英文入口文案。
2. OrgLayout 按工作区实际宽度切换布局。小于 700 px 时，标题栏的按钮打开左侧导航抽屉。切换页面或按 Esc 可关闭。收紧了窄屏搜索和会话设置入口。复用 Drawer 的焦点管理，增加左侧打开选项，默认方向仍为右侧。
3. DocsPage 根据文档区域宽度决定目录布局。固定目录至少需要 240 px，并为正文面板预留 560 px，空间不足时使用临时目录抽屉。临时收起不写入桌面的折叠偏好。“我的文档”在树隐藏时提供文件列表，窄列表将更新人与时间合并到文件名下方。文档标题与批注入口放在同一行。
4. 在现有测试中覆盖从主区或侧栏搜索成员并打开私聊，以及收起文档树后从文件表打开正文。

### 接口、SQL 和配置

扩展现有 `GET /v1/organizations/{organizationID}/spaces/{spaceID}/docs` 的可选 `view=recent`。仅用于个人容器根请求，不能指定父目录。省略参数继续执行目录浏览。请求沿用组织和空间读权限校验，用户 ID 来自认证上下文。更新了 OpenAPI 描述、生成的 TS 类型和 API 客户端。新增的只读查询如下，参数按空间、用户排列。

```sql
SELECT n.id::text, n.space_id::text, n.set_id::text, n.owner_user_id::text, n.parent_id::text,
       n.kind, n.title, n.position, n.size_bytes, n.content_type, COALESCE(n.file_key, ''), COALESCE(n.file_ext, ''),
       n.created_by::text, n.updated_by::text, COALESCE(NULLIF(u.full_name, ''), u.email),
       n.created_at, n.updated_at, n.version,
       EXISTS (SELECT 1 FROM openfox.doc_nodes c WHERE c.organization_id = n.organization_id AND c.parent_id = n.id)
  FROM openfox.doc_nodes n
  JOIN openfox.users u ON u.id = n.updated_by
 WHERE n.organization_id = openfox_private.current_organization_id() AND n.space_id = $1::uuid AND n.set_id IS NULL
		AND n.owner_user_id = $2::uuid AND n.kind <> 'folder'
		ORDER BY n.updated_at DESC, n.id LIMIT 12;
```

本轮没有修改部署配置、依赖、业务表结构或迁移脚本，也没有对已有业务数据执行修复 SQL。集成验证在独立临时测试库应用项目已有迁移。前后端一起更新即可使用新视图。回退时先还原前端，再还原文档 API 与客户端契约。已经由用户确认保存的电脑配置属于正常配置版本，回退代码不会撤销该操作。
