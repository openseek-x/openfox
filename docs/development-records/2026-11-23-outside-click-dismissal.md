# 点击外部关闭抽屉与弹窗

## 交互与实现

共享弹窗、抽屉和菜单按指针按下时的浮层顺序处理外部点击。一次点击空白处只关闭最上面一层。非模态抽屉允许背景控件接收这次点击，因此可以直接切换任务或使用导航。

任务详情、评论话题、Agent 和小队设置均复用这一行为。设置抽屉沿用未保存修改确认。放大的指令编辑器收起后保留草稿与光标。自动化编辑器使用已有取消回调，首登向导关闭后保留当前步骤，下次进入组织时继续。搜索筛选器的操作符菜单和文档编辑器的斜杠菜单也支持点击外部收起。

## 验证与修正

- 原组件测试通过后，Chromium 实测发现点击另一张任务卡会短暂打开新任务，随即返回列表。浏览器已替换历史记录，但 React 仍显示旧抽屉。现在只在同一次点击没有触发导航时执行延迟关闭，同时比较地址和历史项状态以支持重复点击同一卡片。该时序已有回归用例。
- 指令编辑器的焦点测试发现，浏览器会在收起后把焦点移到遮罩。遮罩现在阻止这次默认聚焦，草稿、光标和原输入框焦点均有断言。
- 使用本地模拟 API 在 Chromium 验证了抽屉内点击、空白处关闭、切换任务、重复选择同一任务、背景导航、后退恢复及菜单逐层关闭。
- Vitest 的 28 个相关测试文件共 422 项全部通过，覆盖共享组件、任务、设置、搜索、编辑器与首登流程。工作区 `pnpm typecheck`、改动文件的 Prettier 检查及 `git diff --check` 均通过。
