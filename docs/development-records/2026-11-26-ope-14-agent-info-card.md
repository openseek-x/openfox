# OPE-14 · 点击 Agent 头像查看资料

消息、任务、目录、选择器和集成页面通过 Agent ID 打开同一个信息卡片。点头像查看资料，点行内其他位置继续原来的操作。小队消息优先使用消息或运行记录的作者。收件箱新增可选的 actor_agent_id，与界面显示的发起人来自同一来源。

卡片复用现有指派面板、对话路由和设置抽屉。有权读取详情后才显示操作，已归档或禁止单聊、指派的 Agent 会禁用相应按钮。设备数据按电脑与授权匹配，展示可用的并发占用、OpenFox 存储统计。

浏览器回归用例位于 tests/frontend/e2e/agent-info-card.spec.ts，使用模拟接口检查头像点击、权限、键盘和三个快捷入口。消息组件另有实际作者与会话 Agent 不同时的回归断言。

## Chromium 复测返修

以 `8d6babd` 的执行报告 `fc4b0df1` 为基线。列表与收件箱保留整行的任务按钮，头像单独接收鼠标和键盘激活。历史回复和运行头部按作者 ID 取资料，读取失败时可从原 ID 尝试查看资料，小队消息缺作者 ID 时显示「未知作者」。@ 菜单把候选姓名与开卡动作分别命名，从候选返回可以继续编辑原草稿。

卡片复用目标空间的任务写权限和服务端对独立 Agent 目录条目的过滤。目录截断时按同一规则精确查询指定 ID，避免普通成员因未列在前 500 项失去操作。按编号搜索已有任务也限定在目标空间。

`OPENFOX_WEB_PORT=29816 pnpm test:e2e agent-profile-regression agent-info-card` 使用 Chromium 和模拟接口核对 C01–C06、R01、截断目录及跨空间搜索。C06 使用普通可写成员。数据库集成测试 `TestAgentsCrews` 验证按 ID 查询仍过滤专属成员。真实账号验收及独立复测结果见 HiFox 任务评论。
