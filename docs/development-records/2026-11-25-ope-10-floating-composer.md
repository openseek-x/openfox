# OPE-10 Agent 对话悬浮输入框

新对话的输入框与 Agent 欢迎区一起居中。已有对话的输入框在底部独立占位，消息可以滚动到末尾。卡片使用主题浮层阴影与 22 px 圆角，底部留出 20–24 px 空间。

附件入口使用圆形回形针按钮。待发送文件以胶囊显示文件名、大小和移除入口，长文件名按可用宽度截断。发送和停止共用 32 px 的操作位置，发送可用时显示主题主色。独立会话和任务内 AI 面板共用此样式。

## 浏览器验收

从仓库根目录执行 `OPENFOX_WEB_PORT=4394 pnpm test:e2e prompt-kit.spec.ts` 可重放 15 项浏览器用例。接口使用 Playwright 模拟，无需测试账号。

- 中英文、浅色和深色下检查了发送按钮的空草稿、仅附件、悬停与清空状态，以及输入法回车、换行、自适应高度和工具栏对齐。
- 任务 AI 面板收至 320 px 后验证了快捷回复、提及与模型菜单。测试视口及宽度断言已与任务正文的 560 px 预留和窄屏视图切换对齐。
- 另用 390 × 844 视口检查新建和已有 Agent 会话，输入框及发送按钮均在可见范围内。
